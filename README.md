# Bezier Playground

A web application that visualizes Bézier curves with an interactive interface. Users can drag control points and observe how the curve dynamically responds in real time.

**Live Demo:** [Bezier Playground on GitHub Pages](https://expdev-mul.github.io/Bezier-Playground/)

## Features

- Real-time Bézier curve rendering
- Interactive manipulation of control points
- Supports multiple curve types: linear, quadratic, cubic, and higher
- Visual feedback with guiding lines and control handles

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/Bezier-Playground.git
   ```
2. Open `index.html` in any modern web browser.

## Notes

Built entirely with HTML, CSS, and JavaScript. This project is intended for learning, demonstration, and experimentation with Bézier curves and related graphics techniques.
